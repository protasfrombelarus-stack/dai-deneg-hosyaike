ДАЙ ДЕНЕЖКУ ХОЗЯЙКЕ — PWA

В комплекте:
- index.html — приложение
- manifest.webmanifest — название, режим запуска и иконки
- service-worker.js — офлайн-кэш
- icons/ — иконки 192×192 и 512×512

ВАЖНО:
Чтобы установить приложение как PWA и запускать без адресной строки,
файлы нужно разместить на HTTPS-хостинге (или открыть через localhost).
Просто открыть index.html с телефона из папки загрузок недостаточно:
браузер не разрешит полноценную установку и работу service worker.

После публикации:
1. Откройте HTTPS-адрес приложения в Chrome на Android.
2. Нажмите меню ⋮ → «Установить приложение» или «Добавить на главный экран».
3. Подтвердите установку. Приложение появится отдельной иконкой
   и будет открываться в режиме standalone без адресной строки.

Данные платежей сейчас хранятся в localStorage браузера на этом устройстве.
Не очищайте данные сайта/браузера, иначе локальные отметки могут пропасть.
